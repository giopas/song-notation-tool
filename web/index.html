🎸 Song Notation Tool

How this works

  • A song is a list of sections (Intro, Verse, Chorus…), each with a name, an instrument, a repeat count, and one chart line.
  • The chart line is typed, not clicked: chord/note symbols in order, separated by spaces — e.g. B F# G E. Add a fret number right after a symbol with no space to show it too — e.g. 5A means "fret 5 on note A".
  • Repeats: put (x3) after a section's repeat field, or wrap part of a line in brackets with a repeat — [5A 7D]x2 plays that pair twice before continuing.
  • Riffs: a block referenced by name in more than one section — edit it once, every section using it updates. (Manage riffs from the desktop app for now.)
  • Transpose shifts every chord/fret in a section (or the whole song) by semitones, without rewriting what you typed — safe to undo by transposing back.
  • A parse error in a chart line never clears what you typed — it's shown inline in red under the field, and the last valid render stays visible above it.
